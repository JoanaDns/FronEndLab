# 💻 Exercícios de Front-End — SENAI

Repositório criado para organizar e documentar todos os exercícios, projetos e práticas desenvolvidos durante as aulas de **Desenvolvimento Front-End** no **SENAI**.

---

## 📌 Sobre o Repositório

O objetivo deste espaço é acompanhar a evolução do aprendizado em desenvolvimento web, aplicando na prática os conceitos ensinados pelo professor em sala de aula.

Aqui você encontrará conteúdos relacionados a:
- **HTML5:** Estruturação semântica de páginas web.
- **CSS3:** Estilização, layout (Flexbox/Grid) e responsividade.
- **JavaScript:** Lógica de programação, manipulação do DOM e eventos.
